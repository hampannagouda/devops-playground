# 30 Linux Commands Every DevOps Engineer Should Know

## File & Directory Management
1. **`ls`** – list directory contents
2. **`cd`** – change directory
3. **`pwd`** – print working directory
4. **`find`** – search for files by name, type, size, etc.
5. **`cp` / `mv` / `rm`** – copy, move, and remove files

## Text Processing
6. **`grep`** – search text using patterns
7. **`sed`** – stream editor for filtering/transforming text
8. **`awk`** – pattern scanning and text processing language
9. **`cat`** – display file contents
10. **`less`** – view file contents page by page

## Permissions & Ownership
11. **`chmod`** – change file permissions
12. **`chown`** – change file owner/group
13. **`sudo`** – execute commands with elevated (root) privileges

## Process & System Monitoring
14. **`ps`** – display running processes
15. **`top` / `htop`** – real-time system resource monitor
16. **`kill` / `killall`** – terminate processes
17. **`df`** – show disk space usage
18. **`du`** – show directory/file size usage
19. **`free`** – display memory usage

## Networking
20. **`ping`** – test connectivity to a host
21. **`curl`** – transfer data to/from a server (APIs, downloads)
22. **`netstat` / `ss`** – show network connections and listening ports
23. **`ssh`** – securely log into remote machines
24. **`scp`** – securely copy files between hosts

## Package & Service Management
25. **`apt` / `yum`** – install and manage software packages
26. **`systemctl`** – manage system services (start, stop, enable, disable)
27. **`journalctl`** – view system logs

## Archiving & Compression
28. **`tar`** – archive multiple files into one
29. **`rsync`** – efficiently sync files/directories, locally or remotely

## Scripting & Automation
30. **`crontab`** – schedule recurring tasks (cron jobs)
